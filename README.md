Expense Tracker — Трекер расходов
Автор: Амира Кулиева

Описание
Приложение с графическим интерфейсом (Tkinter) для учёта личных расходов. Позволяет добавлять, фильтровать и анализировать траты с сохранением данных в JSON‑файл.

Возможности:

Добавление расходов с указанием:

суммы (с проверкой на положительное число);

категории (еда, транспорт, развлечения, другое);

даты (с проверкой формата ДД.ММ.ГГГГ).

Отображение всех расходов в удобной таблице.

Фильтрация записей:

по категории;

по конкретной дате.

Подсчёт общей суммы расходов за выбранный период (между начальной и конечной датой).

Сохранение всех данных в файл expenses.json и автоматическая загрузка при запуске программы.

Интуитивно понятный интерфейс с мгновенным обновлением таблицы после добавления или фильтрации данных.

Как использовать
Запуск приложения:

Откройте терминал или командную строку.

Перейдите в папку с проектом.

Выполните команду: python main.py.

Добавление расхода:

Введите сумму в поле «Сумма».

Выберите категорию из выпадающего списка «Категория».

Укажите дату в формате ДД.ММ.ГГГГ в поле «Дата».

Нажмите кнопку «Добавить расход» — запись появится в таблице внизу окна.

Подсчёт суммы за период:

В поле «Начало периода (ДД.ММ.ГГГГ)» введите начальную дату.

В поле «Конец периода (ДД.ММ.ГГГГ)» введите конечную дату.

Нажмите «Посчитать сумму за период» — под кнопкой отобразится итоговая сумма.

Фильтрация по категории:

Выберите нужную категорию в выпадающем списке «Фильтр по категории».

Нажмите «Применить фильтр по категории» — в таблице останутся только записи с выбранной категорией.

Фильтрация по дате:

Введите дату в формате ДД.ММ.ГГГГ в поле «Фильтр по дате».

Нажмите «Применить фильтр по дате» — в таблице отобразятся только расходы за указанную дату.

Просмотр всех записей:

Чтобы сбросить фильтрацию и увидеть все данные, просто обновите таблицу — она автоматически покажет полный список расходов.

Используемые технологии
Язык программирования: Python 3.x.

Графический интерфейс: tkinter (встроенная библиотека Python).

Работа с данными: json (для сохранения и загрузки расходов).

Валидация и обработка дат: datetime (проверка формата даты).

Система контроля версий: Git (репозиторий на GitHub).

Особенности реализации
Валидация ввода:

Сумма должна быть положительным числом (иначе выводится сообщение об ошибке).

Дата должна быть в формате ДД.ММ.ГГГГ (иначе выводится сообщение об ошибке).

Сохранение данных: все расходы сохраняются в expenses.json, что позволяет продолжить работу с теми же данными при следующем запуске.

Мгновенное обновление интерфейса: таблица обновляется сразу после добавления новой записи или применения фильтра.

Удобный подсчёт: быстрый расчёт суммы за любой период — достаточно указать начало и конец периода.

Тестирование
Программа протестирована на следующих сценариях:

Позитивные случаи:

добавление корректного расхода (сумма > 0, правильная дата);

фильтрация по существующим категориям и датам;

расчёт суммы для периода с записями.

Негативные случаи:

ввод отрицательной суммы (выводится ошибка);

пустая строка в поле суммы (выводится ошибка);

некорректный формат даты (ДД/ММ/ГГГГ или текст вместо даты) — выводится ошибка.

Граничные случаи:

максимальная длина текста в полях (не ограничена, но отображается в таблице);

дата на границе месяца/года (корректно обрабатывается datetime).

Примечания
При первом запуске файл expenses.json создаётся автоматически.

Для корректной работы фильтрации и подсчёта убедитесь, что даты введены в формате ДД.ММ.ГГГГ.

Данные сохраняются в той же папке, что и main.py.

Приложение не требует интернет‑соединения и дополнительных API.
